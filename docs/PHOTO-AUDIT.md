# Photo audit

Intake: "ENJ Metal Roofing Photos" (Google Drive), 19 unique JPEGs and one
video, received 2026-09-24. All photos are 1560px on the long side (reduced
by the phone or upload), carry no location data, and all have the same
export timestamp, so the date each job was done is unknown.

Only what is visible in a photo is written on the site. No suburb, date,
steel grade, profile name or colour name is given for any job until ENJ
confirms it. Imported copies are stripped of all metadata.
